How to use the notebooks

Open a tutorial and use Download .ipynb to save the notebook. Follow its installation cell, start Jupyter with python -m jupyter lab, open the downloaded file and choose Run All.

The first run downloads the required files from HistAgent-data. Quick Start downloads only the selected organ packs. The clinical tutorial uses a released ABMIL model instead of training one from scratch.
