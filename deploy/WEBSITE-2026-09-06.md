# HistAgent website update — 6 September 2026

The GitHub Pages site uses a shared H&E-inspired visual system: plum and eosin accents, a light background, self-hosted Sora and IBM Plex Sans fonts, and the existing real RCC tissue image. Both font licenses are included in `docs/assets/fonts/`.

The overview, both workbenches, tutorial directory, and five notebook pages share the new typography, navigation and responsive styling in `docs/assets/design-system.css`. Desktop workbenches keep the tissue, scrollable evidence and chat together; tablet and phone layouts stack the panels. The tutorial generator includes the shared style, and generated notebooks have a single main landmark. Notebook downloads, code cells, outputs, scientific figures, metrics and tutorial destinations are preserved.

## State corrections

- Inference snapshots its spot, image and metadata; obsolete success/error responses cannot attach to a new selection.
- Chat callbacks and retries remain attached to their original evidence card.
- Failed Atlas retrieval retains the prior result and its query provenance explicitly. Successful empty retrieval clears cards/map and disables chat.
- Changing images clears old spots and previews immediately. Images with no tissue sampling spots cannot submit inference.
