# HistAgent website redesign — 14 November 2026

The overview, HistAgent workbench, Atlas Explorer and all six tutorial routes now use a microscopy light-table design: cool white and gray, dark ink text, a restrained cobalt action color, IBM Plex Sans typography and monospace specimen metadata. The overview uses an open specimen layout and unboxed application rows. Workspaces prioritize the tissue field, with quiet input/evidence rails and clearly separated conversation areas. Phone layouts show the HistAgent tissue before setup and keep the analysis toolbar available while scrolling. The notebook generator includes both shared stylesheets for future regeneration.

Scientific text, metrics, figures, downloadable notebooks, all six JavaScript files, model endpoints and service behavior are unchanged. No backend or external visitor access repair is included in this release.

Validation:
- Existing gateway-client/workbench-state suite: 28 tests passed.
- Nine main routes checked for duplicate IDs and missing local links/assets: passed.
- All six JavaScript files match the prior public release byte for byte.
- Browser checks at 1440px, 768px, 390px and 320px included representative overview, workbench, Atlas and notebook surfaces. Narrow workbenches have no document overflow after accounting for the browser scrollbar.
- Keyboard spot selection changes the selected barcode; zoom control changes zoom to 1.50; mobile menu expands; mobile analysis toolbar stays visible while scrolling.
- No browser script errors observed on the workbench or Atlas. Live GPU inference and public visitor access were intentionally not revalidated in this visual release.
